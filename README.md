# Library Management System

> **Status:** Archived Collegiate Project (2025)

A web-based library management platform featuring catalog browsing, user book requests, and administrative circulation management.

## Features
- **Catalog Management:** Search, add, update, and categorize library volumes.
- **Role-Based Workflows:** Separate interfaces for registered student borrowers and administrative staff.
- **Circulation Records:** Issue and return tracking with fine calculation logic.

## Architecture
- **Frontend:** HTML, CSS, JavaScript (React / Vanilla UI)
- **Backend:** Node.js, Express, RESTful APIs
